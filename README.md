# 501 Runner Game

A simple **2D side-scrolling auto-runner web game** where the player runs through a Dhaka street environment and must survive obstacles to reach **501 meters**. This was a paid gig for a campaign of a candidate in Bangladesh National election 2026.

Live link: [501 Runner Game](https://d1asif.github.io/election-runner-2/)

## Technologies Used
- HTML  
- HTML Canvas  
- Vanilla JavaScript  

## Features
- Mobile-first **portrait gameplay**
- **Tap or click to jump** controls
- **Auto-running player character**
- **Distance tracker** (goal: 501 meters)
- **Heart-based health system**
- **Three game entities**:
  - Police (−1 heart)
  - Journalist (−1 heart)
  - Female Model (+1 heart)
- **Sprite sheet animation**
- **Responsive canvas scaling**
- **Start screen, gameplay state, and end screen**
- **Restart and external website redirect buttons**

## Goal
Avoid negative collisions, collect hearts when possible, and **reach 501 meters** to finish the game.
